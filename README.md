# 💡 Модуль управления адресными светодиодами

**Версия платы:** 0.1  
**Файлы проекта:** Altium Designer

---

## 📘 Описание

Модуль предназначен для управления **адресными светодиодами (LED)** с использованием микроконтроллера **ATmega328P**.  
Он может применяться в составе систем освещения, декоративных или интерактивных установок, где требуется гибкое управление цветом и яркостью каждого светодиода.

---

## ⚙️ Основные характеристики

| Компонент | Описание |
|------------|-----------|
| **Микроконтроллер** | ATmega328P |
| **Интерфейс связи** | UART (для отладки и конфигурации) |
| **Входные сигналы** | Оптопары для гальванической развязки внешних сигналов |
| **Аналоговые входы** | 2 канала АЦП |
| **Тип светодиодов** | Адресные (например, WS2812B или аналогичные) |
| **Версия платы** | 0.1 |
| **Разводка** | Выполнена в Altium Designer |
